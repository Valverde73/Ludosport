Supabase Backend (PostgreSQL)

Base de datos en la nube para tiradores y combates

Las credenciales se guardan exclusivamente en el almacenamiento local seguro de este navegador. Si no se configuran, la app funciona al 100% en modo LocalStorage.

¿Cómo inicializar las tablas 'fencers' y 'matches' en Supabase?

1. Entra en tu panel de Dashboard de Supabase y selecciona tu proyecto.

2. En el menú lateral izquierdo, haz clic en SQL Editor.

3. Abre o copia el archivo supabase_schema.sql de este repositorio y pulsa Run.

4. Se crearán automáticamente las tablas fencers y matches con sus políticas públicas RLS y los 14 alumnos iniciales.
